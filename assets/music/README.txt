МУЗЫКА ДЛЯ UNO ONLINE
=====================

Файлы в этой папке:
  menu-loop.ogg   — фоновый трек (Ogg Vorbis)
  menu-loop.mp3   — тот же трек (MP3, для Safari)

Игра проигрывает menu-loop.ogg (если браузер его поддерживает), иначе menu-loop.mp3.
Трек зациклен бесшовно, с плавным появлением и затуханием; громкость и вкл/выкл — в настройках (⚙).

ЛИЦЕНЗИЯ ТРЕКА ПО УМОЛЧАНИЮ
---------------------------
Этот луп создан специально для проекта и распространяется как CC0 (public domain):
можно использовать в любых целях, включая коммерческие, без указания авторства.
Это «тёплый» инструментальный луп (музыкальная шкатулка + маримба + мягкий пэд),
без вокала и ударных — как временное решение, звучащее приятно сразу «из коробки».

КАК ЗАМЕНИТЬ НА ПРОФЕССИОНАЛЬНЫЙ ТРЕК
-------------------------------------
1. Скачайте royalty-free / CC0 трек (спокойный, весёлый, уютный, без вокала и резких ударных).
2. Сконвертируйте при желании в два формата и положите сюда РОВНО с такими именами:
       menu-loop.ogg
       menu-loop.mp3
   (достаточно одного mp3 — он поддерживается везде; ogg лучше лупится без щелчка.)
3. Готово — код сам подхватит новый файл. Ничего в коде менять не нужно.

Если ваш трек «не идеально» зацикливается, код обрезает служебную тишину кодека,
но лучше брать трек, изначально помеченный как «seamless loop».

ПРОВЕРЕННЫЕ ИСТОЧНИКИ (совместимо с коммерческим использованием)
----------------------------------------------------------------
• Pixabay Music (pixabay.com/music) — лицензия Pixabay, бесплатно, без атрибуции.
• YouTube Audio Library — треки, помеченные как без атрибуции.
• Free Music Archive (freemusicarchive.org) — фильтр по CC0 / CC-BY.
• Incompetech (incompetech.com, Kevin MacLeod) — CC-BY (нужна атрибуция) или платно без неё.
• ccMixter (dig.ccmixter.org) — раздел с лицензиями для коммерции.
• OpenGameArt (opengameart.org) — фильтр CC0.
• Chosic (chosic.com/free-music) — агрегатор royalty-free.
